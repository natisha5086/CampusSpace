Build With AI: DevOps 2026
GDG on Campus – Deen Dayal Upadhyaya Gorakhpur University

1. About the Project

CampusSpace is a web-based classroom management system designed to simplify classroom availability, booking and academic coordination at DDUGU.

It helps faculty members find suitable classrooms and prevents overlapping room reservations.

2. Key Features

- Search available classrooms.
- Building-wise room filtering (IET and Deeksha Bhawan).
- Date and time-based availability.
- Capacity-based room filtering.
- Room booking and cancellation.
- Booking conflict prevention.
- Booking history.
- Role selection for different users.

5. How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html in a browser.
4. Explore room availability and booking features.

6. DevOps Implementation

GitHub is used for version control and project collaboration.

GitHub Actions automatically verifies essential project files whenever changes are pushed to the main branch.

7. Important Note

This is an academic working prototype. Local Storage is used for demonstration bookings. The role selector is not production-grade authentication. Official student datasets and institutional deployment require further integration.

8. Project Objective

To develop a reliable and centralised classroom coordination platform that improves room utilisation, prevents scheduling conflicts and helps students receive accurate academic information.
